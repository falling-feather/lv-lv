使用Node.js 24.20.0或更新版本。带有pnpm锁文件的项目使用pnpm；运行命令在仓库根目录执行。已有依赖可直接复用。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

服务地址以终端实际输出为准。三维或WebGPU页面建议使用开启硬件加速的桌面Edge或Chrome。
